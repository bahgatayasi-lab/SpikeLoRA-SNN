# SpikeLoRA-TS reproducibility release

This release contains:

- explicit dataset targets and chronological split manifests;
- an explicit electricity-consumption target,
  `PowerConsumption_Zone1`;
- channel-independent PatchTST and iTransformer baselines;
- strict LoRA and SpikeLoRA-TS parameter freezing;
- complete E1--E4 per-seed results and summaries;
- statistical analyses, uncertainty diagnostics, ramp-regime analyses,
  and resource measurements;
- the completed Colab notebook and standalone Python runner.

The files under `legacy/` are archival development files and are not required
to reproduce the reported results.
